# Film Rental SQL Project

## Project Overview
This project analyzes a film rental store database using SQL queries to extract business insights and practice real-world data analysis problems.

---

## Tools Used
- MySQL
- SQL
- GitHub

---

## Skills Used
- Joins
- Aggregate Functions
- Group By
- Subqueries
- Window Functions
- Date Functions

---

## Files Included
- `schema.sql` → Database structure
- `data.sql` → Sample dataset
- `project.sql` → SQL queries and solutions

---

## Sample SQL Problems
- Find total revenue generated
- Find top rented movies
- Find customers with highest rentals
- Analyze monthly rental trends
- Find category-wise revenue
